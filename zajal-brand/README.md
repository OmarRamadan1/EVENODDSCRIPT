# زَجَل — دليل الهوية (الإصدار 2.0)

الملف النهائي: **[`build/Zajal-Brand-Guidelines-v2.0.pdf`](build/Zajal-Brand-Guidelines-v2.0.pdf)** — ٦٧ صفحة، مقاس 16:9، يُقرأ من اليمين لليسار.

الديك مبني كـ HTML ويُصدَّر PDF، عشان أي تعديل لاحق يتم في سطر نص واحد بدل إعادة تصميم شريحة،
وعشان أرقام الصفحات والفهرس والتباينات تتولّد من الملف نفسه فما تقدرش تبقى غلط.

## البناء

```bash
npm install                 # puppeteer-core فقط، للفحص
node tools/build.js         # يجمّع deck/index.html ثم يصدّر الـ PDF
node tools/build.js --html-only
node tools/qa.js            # فحص التخطيط — يسقط لو فيه محتوى خارج الصفحة
```

`tools/build.js` بيلزّق ملفات `deck/parts/*.html` بالترتيب، وبيحقن سكربت بيرقّم الصفحات
وبيبني صفحتَي المحتوى من الصفحات نفسها. `tools/qa.js` بيفتح الناتج في Chrome وبيبلّغ عن:

- محتوى خارج حدود الصفحة (1280×720)
- عناصر بتكسر هوامش المستند
- نصوص أصغر من الحد المقروء
- صور ما اتحمّلتش

## الأرقام اللي في الدليل من فين

| السكربت | بيحسب إيه |
| --- | --- |
| `tools/color_report.py` | قيم RGB و CMYK ونِسَب التباين لكل تركيبة لون (`tools/colors.json`) |
| `assets/extract.py` | استخراج الشعار والنقشة وصور المنتج من شرائح النسخة السابقة |

الشعار متخزَّن كقناع شفاف واحد (`assets/logo/mark-mask.png`) بيتلوّن من CSS، فكل نسخة لونية
بتيجي من نفس الأصل بدل ما يبقى فيه عشر صور مختلفة ممكن تتفرّق عن بعض.

## أهم ثلاث نتائج قياس

1. **الكريمي على الزيتوني تباينه 2.40:1** — ساقط لأي نص. اتشتق منه زيتوني وظيفي `#6E734A`
   بنفس الدرجة والتشبّع، بيدّي 4.54:1 مع الكريمي.
2. **قيمة الـ RGB في النسخة السابقة كانت لأزرق داكن** `(22, 28, 63)` مش للزيتوني
   `#9DA471` = `(157, 164, 113)`.
3. **أرفع شخط في الشعار = 0.73% من عرضه** — يعني أقل مقاس آمن للأوفست ٢٨ مم وللفويل ٤٨ مم،
   والشعار على اللابيل الحالي ≈ ٢٥ مم. لازم نسخة مبسّطة قبل أي طباعة.
